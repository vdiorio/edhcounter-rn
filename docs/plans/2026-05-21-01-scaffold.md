## Notes for the engineer

- **TDD posture for a scaffold:** Most steps are config — the "test" is build/launch output. A single smoke test (`__tests__/App.test.tsx`) guards that the React entry compiles and resolves the `@/*` alias.
- **Reanimated plugin order:** `react-native-reanimated/plugin` must be the LAST entry in `babel.config.js` plugins. Wrong order → "Reanimated 2 failed to create a worklet" errors at runtime.
- **`react-native-asset` vs manual linking:** RN 0.81 does not autolink asset folders. `npx react-native-asset` is the supported path. If it fails on iOS, fall back to manually adding the fonts in Xcode → Info → "Fonts provided by application".
- **Splash background must match `windowBackground`:** if they diverge, the user sees a flash of color when the splash hides. Both are `#1e1d22`.
- **Do NOT carry over `expo-router`, `expo-*`, `eas.json`, `app.json` plugins, or `patches/` from the current repo.** This is a fresh project; only the listed F-Droid + assets material crosses over.
- **Subsequent plans (02–04, 15, 16, 18) will assume:**
  - `@/*` resolves to `src/*`.
  - All listed dependencies are installed.
  - Jest preset is `react-native`, mocks are in `jest.setup.js`.
  - `App.tsx` lives at `src/App.tsx` and is the only mounted component (Task 5 minimal stub).
